Unlock methods

A password lives in your head, a recovery code lives on paper, and a phone passkey lives on your phone; all three move to a new machine. The master password can be changed below but never removed, and Obscura will not let you remove the last portable way in, because a vault that only this computer can open is a vault you lose with the computer.

Location

The vault can live anywhere you can write - another disk, a removable drive, or a folder inside a mounted encrypted volume. Moving it writes the vault to the new place, checks it landed intact, and only then deletes the old copy.

Backup

An export is every entry in one plain-text file - ids, timestamps, tags, custom fields and two-factor secrets included. It is how you move off Obscura, and how your entries survive a change to the vault format.

Import reads an Obscura export, or a CSV from Bitwarden, Chrome, Edge or Firefox. It adds entries and never replaces one you already have, so importing the same file twice gives you two copies.

Auto-lock

The countdown runs in Rust, not in this window, so a frozen interface cannot keep the vault open.
